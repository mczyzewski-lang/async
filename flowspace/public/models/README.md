# Instructor avatar

`instructor.glb` is generated by `npm run avatar:build` (scripts/avatar/) from CC0 sources:

- Avatar `mpfb.glb` from [met4citizen/TalkingHead](https://github.com/met4citizen/TalkingHead) — created with
  [MPFB](https://static.makehumancommunity.org/mpfb.html), licensed CC0.
- [MakeHuman](https://github.com/makehumancommunity/makehuman) hm08 base mesh and macro/breast/proportion targets — CC0.
- [MPFB](https://github.com/makehumancommunity/mpfb2) game-engine rig skin weights — CC0.

The build reconstructs the full body hidden under the original clothing, paints the yoga outfit into the
skin texture, removes the clothing mesh, facial blend shapes, teeth, tongue and strand eyelashes, and
compresses the result (WebP textures, meshopt geometry). No attribution is required, but credit is appreciated.
